# EverEmber-Releases

Releases of EverEmber, a free-to-play sandbox open-world MMORPG.

## Install for Windows

Download [EverEmber Setup](https://github.com/DandanITman/EverEmber-Releases/releases/latest/download/EverEmber-win-x64-Setup.exe), run the installer, then open the **EverEmber** shortcut.

The launcher checks for updates, installs them when needed and starts the game. An invited EverEmber account is required to play. Existing accounts and characters are preserved.

If you previously used an extracted ZIP, install the launcher once and continue using the same account. Keep using the EverEmber shortcut for future updates.

Close the game before updating. If a download fails, check your connection and select **Retry**. A portable ZIP is also available on the [latest release](https://github.com/DandanITman/EverEmber-Releases/releases/latest).

Requires 64-bit Windows 10 or Windows 11. The launcher includes its .NET runtime.

The initial installer is not Windows code-signed, so Windows may show an unknown-publisher or SmartScreen warning.

This repository contains downloadable client releases. The development source repository is private.
