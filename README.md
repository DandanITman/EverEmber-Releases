# EverEmber-Releases

Releases of EverEmber, a free-to-play sandbox open-world MMORPG.

## Install for Windows

Download [EverEmber Playtest Setup](https://github.com/DandanITman/EverEmber-Releases/releases/latest/download/EverEmber-Playtest-Setup.exe), run it, then open the **EverEmber Playtest** shortcut.

The launcher checks for updates at each start, installs them and starts the game. An invite code is needed to sign up.

No installer? Download the no-install zip from the [latest release](https://github.com/DandanITman/EverEmber-Releases/releases/latest), unzip it and run `EverEmberPlaytest.exe`.

Requires 64-bit Windows 10 or Windows 11. The installer is not code-signed, so Windows may show an unknown-publisher or SmartScreen warning.

This repository holds the downloadable client releases. The development source is private.
